## 可选外部来源

外部资源暂不直接提交到 `assets/`。确定使用后，在这里追加具体文件名和落地路径。

- [Kenney 支持页](https://kenney.nl/support)：Kenney 资产页的公共领域 CC0 说明。
- [Kenney UI Pack](https://kenney.nl/assets/ui-pack)：菜单和 HUD 的中性 UI 参考。
- [Kenney Particle Pack](https://kenney.nl/assets/particle-pack)：命中火花和烟尘参考。
- [Kenney Game Icons](https://kenney.nl/assets/game-icons)：气槽、暂停和设置图标参考。
- [Ninja Adventure](https://tmhsdigital.github.io/Free-Game-Dev-Assets/entry/ninja-adventure/)：CC0 像素原型素材，和当前画风不匹配。
- [AutoSprite Ninja](https://www.autosprite.io/free-sprite-sheets/ninja)：CC0 侧视忍者动画参考，使用前仍需记录具体文件。

## 引入检查
